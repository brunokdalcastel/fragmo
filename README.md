# Fragmo

Captura de tela 100% local para Windows.

## Pré-requisito

- [.NET 10 SDK](https://dotnet.microsoft.com/download)

## Comandos

```powershell
dotnet build
dotnet test
dotnet run --project src/Fragmo
```

## Privacidade

O Fragmo não acessa a rede e não tem telemetria. As capturas e as configurações ficam só no seu computador
(`%USERPROFILE%\Pictures\Fragmo` e `%APPDATA%\Fragmo`).
